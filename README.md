# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。
- 来源更正流程：记者选择来源、填写原因并关联新材料；编辑确认前报告继续显示原来源与「待更正」提示；确认后旧来源留在来源历史，当前事实改用新材料并生成更正版本；已发布报告快照冻结不改写，可查两次来源差异、申请人与确认人。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
```
