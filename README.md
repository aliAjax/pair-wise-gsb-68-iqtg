# 新闻事实核查证据链与发布审阅工作台

基于React、Chakra UI、Zustand、React Router、TanStack Query、Axios、Vite和TypeScript的独立前端工程。数据使用浏览器本地持久化。

## 功能

- 核查主张列表、搜索、状态筛选和新建。
- 可验证事实树、支持证据、相反证据、置信度和未解决疑点。
- 原始证据、二次来源、待证信息分类与内容哈希留档。
- 证据关系图、来源时间线、多人批注和解决状态。
- 发布前校验、版本记录、完整档案与审计导出。
- 来源更正流程：记者选择来源、填写原因并关联新材料；编辑确认前报告继续显示原来源与“待更正”提示；确认后旧来源留在历史、当前事实改用新材料并生成更正版本；已发布档案冻结不改写，可查询两次来源差异与确认人（亦可驳回）。

## 来源更正流程

1. 记者在事实的支持/相反证据上点击“发起来源更正”，选择旧来源、填写更正原因并关联新材料，申请进入“待编辑确认”。
2. 确认前新材料仅暂存，不进入事实来源列表；报告、关系图与发布内容继续显示原来源，并在事实卡片、来源卡、关系图和复核队列标注“待更正”。
3. 编辑在“编辑复核”页查看两次来源差异后确认或驳回：
   - 确认：旧来源标记 `supersededBy` 留在历史列表，新材料以 `supersedes` 关联旧来源并成为当前依据，生成“来源更正”类型版本，记录确认人、确认时间和意见。
   - 驳回：新材料不生效，报告继续显示原来源。
4. 首次发布时冻结完整 `PublishedSnapshot`；发布后的更正只追加版本，不改写已发布档案。
5. “档案与审计”页和主张导出包含全部更正记录、新旧来源字段级差异、确认人及审计事件。

端口为`18468`。

```bash
npm install
npm run build
npm run dev
```
